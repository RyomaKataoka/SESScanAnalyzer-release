# SES Scan Analyzer（配布用）

Scienta SES で測定した**位置スキャン**（1 フォルダ＝1 スキャン）を読み込み、スペクトル・位置プロファイル・積分強度・ヒートマップの表示、
ピーク／エッジのフィット、**ナイフエッジ法（試料端）によるビームサイズの評価**を行う Windows 用アプリです。
このリポジトリは**実行ファイルの配布専用**です（ソースコードは含みません）。

## ダウンロード

[Releases](https://github.com/RyomaKataoka/SESScanAnalyzer-release/releases/latest) から
`SESScanAnalyzer-<版>-win64.zip` をダウンロードしてください。`SHA256.txt` はファイルが壊れていないかの確認用です。

## 動作環境

- Windows 10 / 11（64 ビット）
- インストール不要。Python や追加ライブラリ、インターネット接続も不要です。

## 使い方（はじめて起動するとき）

1. ダウンロードした zip を右クリック →「プロパティ」→「許可する」にチェックを入れてから展開します（警告が出にくくなります）。
2. 展開してできた `SESScanAnalyzer` フォルダを、**フォルダごと**任意の場所（例：`C:\Tools\SESScanAnalyzer`）に置きます。
   中の `_internal` フォルダは削除・移動しないでください（EXE だけを取り出すと起動しません）。
3. `SESScanAnalyzer.exe` をダブルクリックで起動します。署名のない実行ファイルのため、初回は
   「Windows によって PC が保護されました」と表示されることがあります。「詳細情報」→「実行」を選んでください。

操作方法は、アプリの「ヘルプ」タブ →「マニュアル」（F1 キー）で開くマニュアルにまとめています。
同梱の合成サンプル（`sample` フォルダ）を使った「はじめての操作」から読むのがおすすめです。
概要は [使い方.txt](使い方.txt) にもあります。

ハッシュ値の確認（任意）：PowerShell で次を実行し、`SHA256.txt` の値と一致することを確かめます。

```
Get-FileHash .\SESScanAnalyzer-<版>-win64.zip -Algorithm SHA256
```

## 注意

- 元のデータファイルは変更しません。設定ファイル・レジストリ・PATH・既存の Python も変更しません。
- `sample/` のデータは計算で作った合成データです（実測ではありません）。
